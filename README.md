# 🚗 Dealership Java Web Application

A full-featured Java-based web application for managing a vehicle dealership. This platform provides role-based functionality for both admins and users, supporting real-time operations on vehicle and user data.

🔗 **Live Demo**: [https://dealership.fly.dev/Dealership/index.jsp](https://dealership.fly.dev/Dealership/index.jsp)

---

## 🌟 Features

### 🔧 Admin Capabilities (CRUD)
Admins have full control over the system and can:
- **Create** new users and vehicles.
- **Read** and view all registered users and listed vehicles.
- **Update** user or vehicle details (e.g., contact info, descriptions, images).
- **Delete** users or vehicles from the system in real time.

### 👤 User Capabilities
Regular users can:
- **Browse vehicles** available in the dealership.
- **Save vehicles** to a personal list, similar to a wishlist, to view later.
- **View details** about each vehicle including model, year, location, and more.

---

## 🛠️ Tech Stack

- **Java** (Servlets, JSP)
- **JDBC** (for database communication)
- **MySQL** (backend database)
- **Tomcat** (Java web server)
- **HTML/CSS/JavaScript** (for frontend UI and dynamic form logic)
- **Bootstrap** (for responsive layout and styling)
- **GeoNames** (API used for fetching States and Cities)
